# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

## [2.3.12.0] - 2026-09-21
### Added
- HEIF/HEIC image format support, including RGB/RGBA to BGRA conversion.
- HEIF search type in the GUI.
- libheif version display in the About window.
- New folder picker dialog.

### Changed
- Updated project to compile with Microsoft Visual Studio 2022.

### Fixed
- Memory release functions to prevent memory leaks in HEIF handling.

## [2.3.11.0] - 2018
### Added
- New folder picker implementation.
